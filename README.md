# SQL Assignment - Query Fundamentals & Data Warehousing


## Files
- `setup_database.sql` - creates the `sql_assignment` database, all required tables, and sample data.
- `queries.sql` - contains the corrected solutions for all 10 assignment questions.

## How to run

1. Open MySQL Workbench or MySQL command line.
2. Run `setup_database.sql`
3. Run `queries.sql`
4. Execute each query separately and compare the result with the assignment examples.
